# SCENE — シェアサロン予約プロトタイプ

美容師や店舗から案内されたURLで店舗を固定し、会員登録をせずにスタッフと日時を選んで予約するHTMLモックです。運営側には店舗管理者・店舗スタッフ・システム管理者の画面を用意しています。データベースやWebサーバーは使いません。

## 開き方

**index.html** をブラウザーで直接開いてください。顧客向けの初期画面は SCENE 中目黒店です。

## 画面と操作

- **予約ページ**：店舗検索や店舗切替はありません。リンク先の店舗が固定され、店内のスタッフ写真・プロフィール・作品リンク・メニューを見て予約できます。メニューは一つだけ選択。7日分の日付と時間を同じ表で比べ、枠を選択後に「次へ」で進みます。店舗情報の「営業時間・アクセス」を開いても表示が崩れないよう修正しています。予約完了時にスタッフの空きとセット面の空きを確認し、セット面を自動割当します。席番号は顧客に表示しません。
- **店舗管理者画面**：`index.html?mode=admin&role=owner&owner=owner-a`。オーナーAは吉祥寺店と中目黒店を切り替えられます。`owner=owner-b` ならオーナーBの三軒茶屋店だけを表示します。管理者はスタッフの肩書・ログイン用メールアドレス・プロフィール、スタッフの非公開化・再公開、設備、予約、顧客履歴を管理します。「勤務スケジュール」では自分または各スタッフを選び、ドラッグで日付ごとの受付時間をまとめて登録・解除できます。「店舗休業日」は別画面で日付または期間を指定し、その期間のスタッフ受付時間を解除します。
- **店舗スタッフ画面**：`index.html?mode=admin&role=staff&staff=rena`。本人の勤務スケジュールとプロフィール画面を切り替えられます。勤務スケジュールでは本人の7日間を表示し、セルを上下にドラッグして時間帯を登録・解除します。予約済み時間と店舗休業日は編集できません。プロフィールは本人だけが編集し、写真・紹介文・作品リンクを更新できます。LINE通知の連携状態をデモ操作できます。お客さまの氏名や電話番号、他スタッフの情報、店舗設定、スタッフ登録・削除は表示しません。別のスタッフは `staff=` に該当するスタッフIDを指定します。
- **システム管理者画面**：`index.html?mode=admin&role=system`。「実店舗管理」でシェアサロン物件を登録し、「店舗管理」で物件に屋号店舗を紐付け、オーナーを割り当てます。実店舗と屋号店舗は複数登録できます。システム管理者への導線は顧客向け・店舗管理者向け画面に表示しません。
- **顧客記録**：店舗管理者は予約カレンダーからお客さまの連絡先、前回の施術メモ、同一店舗の予約履歴を確認できます。名前には「様」を付け、来店結果は「施術済み／未来店（連絡あり）／未来店（連絡なし）」として予約ごとに記録します。

## 予約と設備の考え方

実店舗（シェアサロン物件）の下に、オーナーの屋号店舗を置きます。店舗管理者は自分に割り当てられた屋号店舗内のスタッフ・設備を管理します。スタッフとセット面は事前に固定ペアにしません。初期状態では空き時間を登録せず、予約画面はすべて×です。スタッフ本人は7日表示のカレンダーで日付ごとの空き時間をドラッグ登録し、店舗管理者は自分と全スタッフの勤務を変更できます。店舗休業日は専用画面で日付または期間を指定し、休業期間に重なるスタッフ時間を解除します。期間内に確定済み予約がある場合は登録できません。休業日の解除後、受付時間は自動復元しません。お客さまがスタッフ・メニュー・日時を選ぶと、表示時点ではスタッフとセット面の双方が空いている枠だけを○にし、それ以外を×として選択不可にします。最終確定時にもう一度空きを確認し、利用可能なセット面を割り当てます。シャンプー台は設備登録しません。

## デモ状態と制約

- 予約・運営変更・プロフィール写真・LINE連携状態は、ブラウザータブ内の `sessionStorage` に保持します。同じタブで画面を切り替えても残り、タブを閉じると初期状態に戻ります。
- ロールと店舗の切替はデモ用URLによる画面表示です。認証もサーバー側のアクセス制御もありません。本番ではシステム管理者・店舗管理者・スタッフ全員がメールアドレスでログインし、全APIで契約者・所属店舗・スタッフ本人を認可します。システム管理者による顧客情報の閲覧・編集は監査記録に残す必要があります。
- 予約確定、実店舗・屋号店舗・スタッフ・設備の登録、スタッフ非公開化・再公開、プロフィール編集、パスワード再設定メールの送信表示、予約取消、来店記録はこのブラウザー内だけで動作します。写真はアップロード時に縦3:4へ切り抜き、720×960 pxのJPEGに変換します。メールやLINEの通知、認証、決済、SMS認証、予約変更、実際のアカウント発行は接続していません。
- デモ用のスタッフプロフィール写真と顧客・美容師・料金・請求額・SNSリンクは架空です。プロフィール写真は人物を見分ける画面例として用意した生成画像です。
- 空き枠の競合判定は画面モック内の簡易ロジックです。本番では予約確定時にサーバーでスタッフとセット面の両方を一括・排他的に確保します。
